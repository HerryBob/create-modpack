# create-modpack

基于机械动力（Create）的 Minecraft **1.21.1 NeoForge** 整合包开发项目。

追求「贴近现实、尽量复杂」的生存科技整合包：硬核生存（体温/口渴/营养/四季）+ 机械动力科技线（双轨制配方）+ 天气系统（季节风暴/雷暴灾难）+ 远期武器/空岛规划。

## 仓库内容

| 路径 | 说明 |
|---|---|
| `整合包分析.md` | 总体规划文档：阶段划分、科技线、天气系统、远期规划 |
| `手册.md` | 玩家手册《幸存者手札》（替代新手引导） |
| `边玩边开发.md` | 分章玩法设计 |
| `kubejs/` | 全部 KubeJS 开发脚本（配方 / 事件 / 汉化 / 数据包） |
| `config文件/` | 模组配置（源自 7.0 更新目录） |
| `mods_list.txt` | 模组清单（168 个） |
| `*.html` | 配方体系分析可视化 |

## 说明

- 不含游戏客户端/服务端与模组本体（jar），仅开发产出物
- 资源包（resourcepacks/）与光影（shaderpacks/）为 zip，未入仓，见仓库讨论区说明
- 详细开发进度见 `整合包分析.md`
