阶段评估：自举链成立 合理

材料链闭环：铁锭 →（轧机）→ vintage 铁棒 →（卷簧机）→ 铁弹簧 → 全部早期机器。轧机本身用 worldcrafting（机壳+传动轴×2）解锁，整条链不碰黄铜、不碰精密机构，符合"与机械动力同级、阶段一"定位。

中期门槛清晰：黄铜机壳 + 精密机构只出现在真空室 / 车床 / 激光，与 Create 中期节点（吹炼炉出黄铜）对齐。激光头要石英 = 下界材料，与激光机的中期定位匹配。

两个待调点：
① 振动台加了精密机构（SAS 行）—— 振动台其余材料全是木/活塞/弹簧，精密机构（黄铜时代）会把它从"开局第三天"卡到中期。若坚持纯阶段一，建议换成传动轴或弹簧。
② 落锤槽盖用黄铜粒×3 —— 黄铜需吹炼炉，落锤本体却是早期机器，做它的配件反而要等黄铜。若想更早，可改铁粒序列组装。
已确认无自举死锁：卷簧机 = 安山机壳 + 卷簧机轮；卷簧机轮 = 安山合金×4 + 铁块；两者都只需要铁 / 安山合金，不需要任何 Vintage 机器产物，链条可从生存第一天搭起来。
数据口径：createvintageneoforged.js（KubeJS 机器 + 零件配方）+ worldcrafting.js（弯曲压机世界结构）+ 模组原生 coiling/sequenced_assembly 配方交叉核对。v1.3.7 · NeoForge 1.21.1 · Create 6.0.10。
