# 🐎 马匹繁育系统 (Horse Breeding System)

一个为 Minecraft 设计的沉浸式马匹繁育增强系统，通过 KubeJS 实现。

## 📋 系统概述

本系统在保持原版 Minecraft 繁育机制的基础上，为马匹繁育添加了遗传学特性，使马匹的速度属性能够在繁育过程中遗传和优化。系统完全静默运行，不会产生任何游戏内提示，确保最佳的游戏沉浸感。

## ✨ 核心特性

### 🧬 遗传算法
- **速度遗传**：幼马的速度基于父母马的速度计算
- **概率分布**：
  - 89.9% - 父母平均速度 ± 0.02 的小幅变化
  - 10.0% - 最高/最低父母速度 ± 0.02 的变化
  - 0.1% - 最高/最低父母速度 ± 0.2 的大幅变化
- **速度范围**：0.06 - 0.75 (对应游戏内 4.8 - 60 格/秒)

### 🎯 自动驯服
- 如果父母马都已驯服，幼马将自动驯服
- 幼马的主人自动设置为发起繁育的玩家
- 保持繁育血统的连续性

### 🔧 兼容性设计
- **完全兼容原版**：不修改任何原版繁育机制
- **物品支持**：使用原版繁育物品（金胡萝卜、金苹果、糖）
- **事件处理**：智能延迟处理，避免与原版逻辑冲突
- **多人友好**：完全支持多人服务器环境

## 🛠️ 技术实现

### 数据管理
- **内存优化**：最大存储 100 条繁育记录
- **自动清理**：每 60 秒清理过期数据
- **即时清理**：幼马匹配后立即清理对应记录
- **防重复**：智能去重机制防止重复记录

### 性能保障
- **轻量级设计**：总内存占用 < 50KB
- **高效算法**：O(1) 查找和删除操作
- **资源控制**：严格的容量限制防止内存泄漏

## 📦 安装要求

### 必需模组
- **KubeJS** (6.x+)
- **Architectury API**
- **Forge** 或 **Fabric** (对应版本)

### 安装步骤
1. 确保已安装上述必需模组
2. 将 `horse_speed.js` 放入 `kubejs/server_scripts/` 目录
3. 将 `tools.js` 放入 `kubejs/server_scripts/` 目录
4. 重启服务器或使用 `/kubejs reload server_scripts` 重载

## 🎮 使用方法

### 基础繁育
1. 准备两匹已驯服的成年马
2. 使用金胡萝卜、金苹果或糖喂食其中一匹马
3. 确保另一匹马在 16 格范围内且处于"恋爱"状态
4. 系统将自动记录繁育信息
5. 幼马出生时将自动获得计算后的速度属性

### 速度检测
- 手持时钟右键点击马匹可静默检测其速度
- 系统会在后台记录速度信息，无游戏内显示

### 优化策略
- **选择性繁育**：选择高速度的马作为种马
- **代际管理**：保留每代最优秀的个体
- **耐心培育**：从 0.35 速度培育到 0.75 最高速度大约需要 200-500 次繁育

## 🚀 高级特性

### 繁育优化算法
系统使用复杂的概率分布来模拟真实的遗传过程：

```javascript
// 速度计算示例
if (random < 0.001) {
    // 0.1% 概率：大幅突变
    speed = extremeSpeed + (Math.random() - 0.5) * 0.4
} else if (random < 0.101) {
    // 10% 概率：基于极值的小幅变化
    speed = extremeSpeed + (Math.random() - 0.5) * 0.04
} else {
    // 89.9% 概率：基于平均值的正常变化
    speed = averageSpeed + (Math.random() - 0.5) * 0.04
}
```

## 🔧 故障排除

### 常见问题

**Q: 幼马速度没有改变？**
A: 确保父母马都是成年且已驯服，繁育发生在 16 格范围内。

**Q: 系统是否影响原版繁育？**
A: 不会。系统只在原版繁育成功后添加速度属性，不修改任何原版逻辑。

**Q: 如何知道系统是否正常工作？**
A: 系统静默运行。可以通过观察幼马速度是否基于父母速度来判断。

**Q: 服务器性能是否受影响？**
A: 不会。系统设计为轻量级，对服务器性能影响微乎其微。
